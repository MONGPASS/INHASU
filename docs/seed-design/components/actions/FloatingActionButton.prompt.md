Round icon-only button that floats over scrolling content, bottom-right.

```jsx
<FloatingActionButton size="medium" icon={<Icon name="write_regular" size={22} />} />
```

- Paper-floating fill on a soft shadow — never carrot. The carrot fill is reserved for BoxButton.
- Shadow is size-specific: 0 2px 6px rgba(0,0,0,.16) at medium, 0 1px 3px rgba(0,0,0,.28) at small.
