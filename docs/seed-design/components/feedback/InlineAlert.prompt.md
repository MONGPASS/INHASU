A compact notice attached to the element it describes — tighter and quieter than a Callout.

```jsx
<InlineAlert variant="danger" icon={<Icon name="warning_fill" size={16} />}>가격은 숫자만 입력할 수 있어요.</InlineAlert>
```

- Variants: normal, info, success, danger. `weight="strong"` swaps the tint for a solid fill; Seed's own guidance is to use it only when the message really must be noticed.

**Provisional colours.** Seed defines this family's options but has not published its colour/layout spec; the tints here follow the Callout system.
