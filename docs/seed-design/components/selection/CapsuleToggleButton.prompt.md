Soft capsule toggle — the quiet in-card version of BoxToggleButton.

```jsx
<CapsuleToggleButton size="small" icon={<Icon name="add_regular" size={16} />}>팔로우</CapsuleToggleButton>
```

- Unselected is gray-alpha-50 fill on gray-900 text; selected flips to carrot-tint on carrot text.
- Radius is a literal 18px (small) / 16px (xsmall), not a full pill.
