Pill chip with an on/off state — independent filters in a horizontal row.

```jsx
<ChipToggleButton defaultSelected>나눔</ChipToggleButton>
<ChipToggleButton>거래 가능</ChipToggleButton>
```

- Selected fills gray-800 with gray-00 text — dark, not carrot.
- For a single-choice row use ChipRadioGroup instead.
