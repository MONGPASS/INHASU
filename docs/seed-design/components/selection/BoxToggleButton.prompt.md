A BoxButton with a persistent on/off state.

```jsx
<BoxToggleButton variant="secondary" defaultSelected prefixIcon={<Icon name="heart_fill" size={16} />}>관심</BoxToggleButton>
```

- On `primary`/`primary-low`, selecting *quiets* the button (secondary-low fill). On `secondary`, selecting *brightens* it (primary-low fill).
- Same size ramp as BoxButton minus xlarge.
