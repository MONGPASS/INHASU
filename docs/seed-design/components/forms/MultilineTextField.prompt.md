Multi-line input — item descriptions, post bodies, report details.

```jsx
<MultilineTextField label="자세한 설명" placeholder="올릴 게시글 내용을 작성해주세요." maxLength={1000} rows={6} />
```

- Single size: 6px radius, 16/12 padding, body-m1 (16px) field text.
- The character counter sits inside the field, right-aligned, 4px under the text.
