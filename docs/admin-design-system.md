# 은하수 관리자 공통 디자인

관리자는 `src/styles/admin-unified.css`를 기준으로 한다. 흰색 업무 카드와 옅은 회색 작업 배경, 민트 강조색을 사용한다. 기존 예약·견적·상품·배정·콘텐츠의 처리 흐름과 상태 의미는 유지한다.

| 항목 | 기준 |
| --- | --- |
| 폰트 | Pretendard, 본문 14px, 목록/입력 13px, 보조 11–12px |
| 화면 제목 | 28px, 좁은 화면 24px |
| 구역 제목 | 18px |
| 강조색 | `--admin-accent: #16856f`, 밝은 바탕 `#edf8f4` |
| 작업 배경 | `#f6f7f9` |
| 카드 | 흰색, 1px `#e6e9ee`, 모서리 12px |
| 기본 버튼/입력 | 높이 40px, 모서리 8px |
| 목록 안 작은 버튼 | 높이 32px, 모서리 6px |
| 카드 안 여백/구역 간격 | 24px |
| 펼친 사이드바 | 240px, 흰색, 민트 바탕 선택 상태 |
| 접힌 사이드바 | 기존 68px 아이콘 메뉴 유지 |

기본·작은·아이콘 버튼을 구분하며 달력 날짜와 배정 칩의 밀도를 무조건 40px로 늘리지 않는다. 위험·주의·완료의 상태색은 업무 의미에 따라 보존한다. 키보드 포커스와 비활성 상태도 같은 규칙을 사용한다.

`AdminLayout`은 공통 CSS를 직접 읽는다. `AdminQuoteDesk`는 같은 CSS 원본을 `?inline`으로 읽어 같은 출처의 관리자 iframe에 한 번의 style 요소로 적용한다. 별도의 복사본을 만들지 않는다. 새로운 견적 도구를 추가하면 이 경로에서 공통 스타일이 적용되는지 확인한다.

예약 v7의 공통 카드·버튼 도우미와 대시보드 CSS Module도 위 변수를 사용한다. 페이지별 CSS에서 민트 값을 다시 고정하지 말고 `--admin-*` 변수를 참조한다. 새 CSS는 `.admin-app-wrapper` 또는 `html.admin-embedded`에 한정한다. 견적 문서의 인쇄 스타일은 `@media screen` 규칙의 영향을 받지 않는다.

확인은 로컬 합성 자료(`npm run dev`, `/__local-admin`)로 대시보드, 통합 예약, 상품, 콘텐츠 및 iframe 견적 도구를 순회한다. `npm test`, `npx tsc --noEmit -p tsconfig.app.json`, `npm run build`를 실행한다. 운영 고객 자료를 수정하거나 발송하여 디자인을 검증하지 않는다.
