# 관리자 화면 리디자인

디자인 기준은 사용자가 제공한 `Admin Dashboard.html`의 최신 템플릿이다. 원본 파일의 SHA-256은 `9A9538EE2C0AB3E1D91BF0A3202DEBDC3CF838EBEC74941C0F9B9B29A92AD278`이다. HTML에 포함된 JSON 템플릿을 읽어 화면 구조와 스타일을 확인했으며, 프로토타입 런타임·샘플 고객·서명·로그인 정보는 서비스에 넣지 않는다.

## 화면 연결

| 디자인 영역 | 실제 관리자 경로 |
| --- | --- |
| 로그인·메뉴·검색·알림 | `/admin/login`, 공통 `AdminLayout`·`AdminSidebar` |
| 대시보드·유입 경로 | `/admin` |
| 통합 예약·고객 상세·7개 업무 탭 | `/admin/reservations`, `/admin/customer-workspace/:source/:id` |
| 견적 문의·5단계 작성 | `/admin/quote-desk/inbox`, `/admin/quote-desk/builder` |
| 상품 목록·상품 편집·카테고리 | `/admin/products`, `/admin/categories` |
| 가이드·숙소·차량 | `/admin/quote-desk/resources` |
| 후기·FAQ·매거진·일반 문의 | `/admin/reviews`, `/admin/faq`, `/admin/magazines`, `/admin/inquiries` |
| 홈 메인·바로가기·이벤트·테마 | `/admin/banners` |
| 투어 캘린더 | `/admin/calendar` |

코스·일정·여행지와 문서 템플릿 등 실제 서비스의 추가 화면에도 공통 관리자 스타일을 적용한다. 숙소 현지 운영의 목록·행 펼침 구조는 사용자가 별도로 지정한 기존 디자인을 유지한다. 중복 제거·메뉴 통합과 이전 주소의 리다이렉트도 유지한다.

## 데이터와 동작

- 대시보드의 기본 집계는 서버가 반환한 계정별 자료를 사용한다. 기간별 매출은 예약 접수일의 한국시간 날짜를 기준으로 계산하며, 누락된 자료와 확인된 0을 구분한다.
- 유입 경로는 방문자·페이지뷰·문의·전환율과 8개 채널을 표현한다. 외부 통계 서비스는 추후 연결한다. 현재는 `—`와 연결 준비 상태를 표시하며, 예약 건수를 방문자로 대체하지 않는다. `AdminTrafficReport`가 공급자와 분리된 연결 규격이다.
- 상품·현재 견적·이전 견적의 출처와 ID를 유지한다. 기존 저장 API, 관리자 권한, 업로드, 초안 보호, 버전 충돌, 문서 공개·발송·실제 서명 증빙을 재사용한다.
- 로그인 상태 유지는 기존 지속 쿠키 정책이 기본이다. 해제하면 동일한 서버 세션 만료 기간과 Secure·HttpOnly·SameSite 속성을 유지하면서 브라우저 세션 쿠키를 발급한다. 관리자 세션 갱신에도 이 선택을 유지하고 로그아웃 시 선택 쿠키와 서버 세션을 정리한다. 고객 Google 로그인 정책은 바꾸지 않는다.
- 메뉴는 760px 이하에서 드로어로 바뀌고, 표와 편집 영역은 각 화면의 콘텐츠 폭에 따라 재배치된다. 대시보드의 작은 집계 카드 두 개는 480px 이하에서 세로로 배치해 숫자와 차트가 겹치지 않게 한다.

검증에는 운영 DB·R2·실제 알림 발송을 사용하지 않는다. 로컬 합성 예약·견적과 기존 회귀 테스트로 저장·권한·문서 동작을 확인한다.
