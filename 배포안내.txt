━━━ 통합 후 처음 배포할 때 한 번만 ━━━
1. 사이트 이미지용 R2 버킷 만들기 (견적 첨부 버킷 leaders-files 와 반드시 따로)
     npx wrangler r2 bucket create milkyway-assets
2. 환경변수 추가 (Pages > inhasu > Settings > Variables and Secrets)
   기존 값(ADMIN_TOKEN, SOLAPI_*, ADMIN_PHONE, SITE_URL …)은 그대로 둡니다.
     ENVIRONMENT           production            ← 꼭 넣으세요 (없으면 테스트용 관리자가 만들어질 수 있음)
     GOOGLE_CLIENT_ID      고객 Google 로그인용
     GOOGLE_CLIENT_SECRET  〃  (Google 콘솔의 리디렉션 URI:
                            https://mongolia-milkyway.com/api/auth/login/google/callback)
     RESEND_API_KEY        고객·관리자 메일 발송 (없으면 메일만 건너뜀)
     ADMIN_EMAIL           예약·입금 신고 알림을 받을 메일
     CRON_SECRET           후기 요청 메일 자동 발송용 (GitHub Actions secret 과 같은 값)
3. 빌드하고 배포
     npm install
     npm run build
     npx wrangler pages deploy dist --project-name=inhasu
   ※ 이제 폴더 전체(.)가 아니라 빌드 결과물 dist 를 올립니다.
   ※ Cloudflare 에 GitHub 을 연결해 두었다면: 빌드 명령 npm run build / 출력 폴더 dist 로 바꿉니다.
4. https://mongolia-milkyway.com/admin/login 접속 → "처음 설정" 화면에서
   기존 견적 관리자 비밀번호(ADMIN_TOKEN)와 새 관리자 이메일·비밀번호를 넣어 계정을 만듭니다.
   (배포 직후 바로 하세요. 한 번 만들면 이 화면은 다시 나오지 않습니다)
5. 여행상품·예약용 표는 배포 후 첫 접속 때 자동으로 데이터베이스에 만들어집니다.
   따로 할 일은 없습니다. (견적 데이터는 건드리지 않습니다)
   ※ 확인하고 싶으면 로그인한 상태로 https://mongolia-milkyway.com/api/migrate-db 를 열어 보세요.
     "Created tables …" 또는 빈 목록이 나오면 정상입니다.
6. 관리자 > 상품 관리에서 여행상품을 등록합니다 (가격은 원화).

━━━ 상품 예약금 받는 방법 ━━━
· 고객이 상품을 예약하면 접수 메일과 화면에 입금 계좌가 안내됩니다.
    우리은행 1002-245-516496  예금주 DAVAASUREN (헬로볼라)
    (바꾸려면 src/constants/company.ts 의 DEPOSIT_ACCOUNT)
· 고객이 마이페이지 예약 상세에서 "예약금 입금 완료했어요"를 누르면
  담당자 메일(ADMIN_EMAIL)과 문자(ADMIN_PHONE)로 알림이 옵니다.
· 관리자 > 통합 예약 관리에서 「입금 신고」 배지를 확인하고 [입금 확인]을 누르면 예약이 확정됩니다.

고객 카카오 알림톡
  ① 견적서를 최초 발행하거나 재발행 → 고객 견적서 직링크 발송
  ② 가이드·차량·숙소 배정 후 확정일정표 최초 공개 → 고객 일정표 직링크 발송
  ③ 고객이 여행계약서에 서명 완료 → 여행 주의사항(가이드북 PDF) 즉시 발송

  여행 주의사항은 카카오 알림톡으로만 발송됩니다 (문자로는 나가지 않습니다)
  두 가지 방법으로 나갑니다
    1) 자동 — 고객이 계약서에 서명한 직후 바로 1회
         "여행계약서 작성이 완료되었습니다. 여행 주의사항을 보내드리니
          여행 준비에 참고해 주세요" 안내와 함께 PDF 링크 발송
         발송에 성공했을 때만 notify.travelNoticeAutoSentAt에 기록해 중복 발송 방지
    2) 수동 — 예약관리 화면 하단 [📘 주의사항 발송] 버튼
         횟수 제한 없이 언제든 다시 보낼 수 있고, 버튼에 마지막 발송일이 표시됨

  ※ 기존 "출발 7일 전 가이드북 자동 발송"은 중단됐습니다.
     Cloudflare에 등록해 둔 스케줄 Worker(milkway-guidebook-reminder)와
     Cron 트리거는 삭제해 주세요. 삭제 전이라도 /api/guidebook-reminders가
     아무것도 보내지 않도록 막아두었으므로 고객에게 중복 안내가 가지 않습니다.
     · GUIDEBOOK_CRON_SECRET 은 Worker를 지운 뒤 함께 삭제해도 됩니다.
     · SOLAPI_TEMPLATE_GUIDEBOOK_ID 는 여행 주의사항 발송에 계속 쓰이므로
       삭제하지 마세요.

  ※ 카카오 알림톡은 사전 승인된 템플릿만 발송할 수 있습니다.
  ※ 발송 실패나 설정 누락이 있어도 견적·일정표 저장은 정상 완료됩니다.

언제 나가나요? (전부 담당자에게 가는 문자입니다)
  ① 고객이 견적요청 접수     → 접수 요약 문자
  ② 고객이 견적 수락         → 수락 + 예약금 안내 표시 문자
  ③ 고객이 입금 완료 신고    → 입금자명 포함 확인 요청 문자
  ④ 고객이 계약서 서명       → 확인·확정 요청 문자
  ⑤ 고객이 여행자 정보 제출  → 제출 알림 문자

  ※ 발송은 백그라운드로 처리돼, 문자가 실패해도 접수·저장은 정상 처리됩니다.
  ※ 환경변수가 없으면 그 알림만 조용히 건너뜁니다 (사이트는 정상 동작).

환경변수 (Pages > milkway-mongolia > Settings > Variables and Secrets)
  [문자 발송 — 없으면 알림 꺼짐]

    SOLAPI_API_SECRET          Solapi API Secret
    SOLAPI_SENDER              등록된 발신 전화번호 (숫자만)
    ADMIN_PHONE                담당자 휴대폰. 쉼표로 여러 명 (01011112222,01033334444)

  [고객 카카오 알림톡 — 없으면 고객 알림만 건너뜀]
    SOLAPI_PF_ID                    연동한 카카오 비즈니스 채널 pfId
    SOLAPI_TEMPLATE_QUOTE_ID        기존 승인된 "견적서 도착" 템플릿 ID
    SOLAPI_TEMPLATE_ITINERARY_ID    승인된 확정일정표 알림 템플릿 ID
    SOLAPI_TEMPLATE_GUIDEBOOK_ID     가이드북(투어 준비물) 알림톡 템플릿 ID
        · 여행 주의사항 발송에 그대로 재사용합니다. 지우지 마세요.
    SOLAPI_TEMPLATE_TRAVEL_NOTICE_ID 여행 주의사항 전용 템플릿 ID (선택)
        · 여행 주의사항은 카카오 알림톡으로만 발송합니다 (문자 대체 없음).
        · 비워두면 위 SOLAPI_TEMPLATE_GUIDEBOOK_ID를 대신 사용합니다.
        · 서명 직후 시점에 맞는 문구로 새 템플릿을 승인받으면 그 ID를 여기에
          넣으세요. 넣는 순간부터 이 템플릿이 우선 적용됩니다.
        · 두 값이 모두 없으면 발송되지 않습니다.

  [폐기된 과거자료 · 실행 금지] 가이드북 자동 발송 Worker 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Solapi에 위 가이드북 템플릿을 승인받고 ID를 Pages의
   SOLAPI_TEMPLATE_GUIDEBOOK_ID에 저장
2. 충분히 긴 비밀번호를 만들어 Pages의 GUIDEBOOK_CRON_SECRET에 저장
3. Pages 다시 배포
    npx wrangler pages deploy . --project-name=milkway-mongolia
4. 자동 실행 Worker에 같은 비밀번호 저장
    npx wrangler secret put GUIDEBOOK_CRON_SECRET --config wrangler.guidebook.toml
5. Worker 배포 (wrangler.guidebook.toml의 매일 00:00 UTC = 09:00 KST 스케줄)
    npx wrangler deploy --config wrangler.guidebook.toml

※ GUIDEBOOK_CRON_SECRET은 Pages와 Worker에 반드시 동일한 값으로 넣습니다.
※ /api/guidebook-reminders는 이 비밀번호 또는 ADMIN_TOKEN 헤더 없이 실행되지 않습니다.
